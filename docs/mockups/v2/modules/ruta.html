¿Cómo de estricta es esta ruta?

Modo rígido

Cliente sigue la secuencia sin saltar. Solo avanza cuando completa el hito. Máxima disciplina, menos libertad. Bueno para founders sin experiencia.

Modo flexible

Cliente puede saltar fases si ya las domina (ej. si ya tiene tráfico, salta directo a fase 03). La IA sugiere reorientaciones si la métrica se estanca.
